## 🔴 5 Existential Risks (Ranked by Severity)

### Risk #1: YouTube API Revocation ⚠️ CRITICAL
- **What:** Google changes API ToS to ban autonomous upload bots
- **Impact:** Product loses its primary function
- **Mitigation:**
  - Position as "semi-automated" (user approves every upload via preview)
  - Never market as "fully autonomous bot"
  - Build manual upload workflow as fallback (generate video → user uploads manually)
  - Clear ToS language: tool assists, user decides

### Risk #2: EU AI Act (August 2026) ⚠️ HIGH
- **What:** Mandatory AI watermarking + provenance metadata for ALL synthetic content in EU
- **Fines:** Up to €15M or 3% of global revenue
- **Impact:** Must embed machine-readable watermarks in generated videos
- **Mitigation:**
  - Add C2PA provenance metadata to all outputs
  - Implement AI disclosure flag in YouTube upload metadata
  - May need to restrict certain features for EU users
  - Add clear "generated by AI" metadata programmatically

### Risk #3: Gemini Free Tier Paywall ⚠️ MEDIUM
- **What:** Google puts Gemini 2.5 Flash behind a paywall or severely throttles limits
- **Impact:** Frictionless onboarding dies (users need credit cards before first script)
- **Mitigation already in blueprint:**
  - Groq is the validation model but could serve as primary LLM backup
  - Architecture fallback routing to open-source models
  - Gemini isn't the ONLY option — the system should be LLM-agnostic

### Risk #4: Copyright Liability ⚠️ MEDIUM
- **What:** AI generates defamatory/copyrighted content, user publishes it
- **Mitigation:**
  - Aggressive ToS indemnification (user responsible for content they publish)
  - Content safety layer (already in our 5-layer validation)
  - CC0 media only for stock assets (already our strategy)

### Risk #5: Algorithm Burnout ⚠️ MEDIUM
- **What:** YouTube further penalizes AI content, channels die, reputation damage
- **Mitigation already in blueprint:**
  - Cross-model validation ensures quality (not volume)
  - Self-improving loop adapts to algorithm changes
  - Shadow ban detection pauses posting when suppressed
  - Preview + regeneration ensures human approval before every upload
